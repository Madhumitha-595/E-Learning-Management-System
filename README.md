##E-Learning Management System

A C++-based E-Learning Management System that organizes online courses, student registrations, enrollments, and course management using object-oriented programming and data structures.

## 📌 Project Overview

EduLearn is an E-Learning Management System developed using C++. It helps manage courses, student registrations, and enrollments through a simple menu-driven interface.

## 🎯 Objectives

- Organize and manage learning courses.
- Register students in the system.
- Enroll students in available courses.
- Display student and enrollment details.
- Apply Object-Oriented Programming and Data Structures.

## ✨ Features

- View available courses
- Register students
- View registered students
- Enroll students in courses
- View enrollment records
- Menu-driven user interface

## 🛠️ Technologies Used

- **Language:** C++
- **Concepts:** Object-Oriented Programming (OOP)
- **Data Structures:** Vectors, Queues, and Stacks (as implemented)
- **Algorithm:** Data searching and record management
- **IDE:** Visual Studio Code
- **Compiler:** GCC (g++)

## ▶️ How to Run

Compile the source code using:

```bash
g++ main.cpp -o edulearn.exe
```

Run on Windows PowerShell:

```powershell
.\edulearn.exe
```

> Replace `main.cpp` with your actual source filename if it is different.
